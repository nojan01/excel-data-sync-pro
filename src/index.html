🚀 Schnellstart

  1. Quelldatei laden: Klicken Sie auf "📂 Quelldatei laden" und wählen Sie die Excel-Datei, aus der Zeilen kopiert werden sollen.
  2. Zieldatei laden: Laden Sie die Excel-Datei, in die die Zeilen eingefügt werden sollen.
  3. Spalten konfigurieren: Legen Sie fest, welche Spalten kopiert werden sollen.
  4. Suchen & Übertragen: Suchen Sie nach Zeilen und übertragen Sie diese zur Zieldatei.

📂 Dateien laden

Quelldatei (Datei 1): Die Excel-Datei, aus der Sie Daten kopieren möchten.
Zieldatei (Datei 2): Die Excel-Datei, in die die Daten eingefügt werden.
Nach dem Laden können Sie das gewünschte Arbeitsblatt auswählen.

🔗 Spalten-Zuordnung

Klicken Sie auf "⚙️ Spalten konfigurieren" um festzulegen:
• Start-Spalte: Ab welcher Spalte die Daten in Datei 2 eingefügt werden (Spalte 1+2 = Flag & Kommentar)
• Duplikat-Prüfung: Welche Spalte zur Erkennung von Duplikaten verwendet wird
• Zu kopierende Spalten: Welche Spalten aus Datei 1 übertragen werden

🔍 Suche

Geben Sie einen Suchbegriff ein und drücken Sie Enter oder klicken Sie auf "🔍 Suchen".
Die Suche durchsucht alle Spalten der Quelldatei. Die letzten 15 Suchen werden gespeichert.

* Beliebig viele Zeichen (z.B. ABC*, *123*) ? Genau ein Zeichen (z.B. A?C findet ABC, ADC, ...)

Erweiterte Suche mit AND/OR:

A AND B Findet Zeilen die sowohl A als auch B enthalten A OR B Findet Zeilen die A oder B (oder beides) enthalten Projekt AND 2025 Beispiel: Projekt-Einträge aus 2025

✏️ Suchergebnisse bearbeiten

Die Zellen in den Suchergebnissen sind direkt editierbar!
Klicken Sie in eine Zelle und ändern Sie den Wert. Bearbeitete Zellen werden gelb markiert.
Die Änderungen werden beim Übertragen zur Zieldatei übernommen.

📤 Übertragung

Flag: A (Add), D (Delete), C (Change) oder Leerzeile
Kommentar: Optionaler Text für Spalte 2
Zur Warteschlange: Sammelt mehrere Zeilen für gemeinsame Übertragung
Direkt übertragen: Fügt die Zeilen sofort zur Warteschlange und überträgt

📋 Warteschlange

Die Warteschlange zeigt alle zur Übertragung vorgemerkten Zeilen.
👁️ Vorschau: Zeigt eine Diff-Ansicht mit allen Änderungen vor der Übertragung
✅ Direkt übertragen: Schreibt alle Zeilen direkt in die Excel-Zieldatei
🗑️ Leeren: Entfernt alle Zeilen aus der Warteschlange

➕ Neue Zeile manuell erstellen

Mit "➕ Neue Zeile" können Sie Zeilen manuell eingeben, ohne sie in der Quelldatei suchen zu müssen.
Ideal für Leerzeilen oder Daten, die nicht in der Quelldatei vorhanden sind.

📂 Datei öffnen

• Klicken Sie auf "📊 Datenexplorer" und dann "📂 Datei öffnen"
• Wählen Sie das gewünschte Arbeitsblatt aus dem Dropdown

Volltextsuche: Durchsucht alle Spalten mit Platzhalter-Unterstützung (* und ?)
Spaltenfilter: Klicken Sie auf "+ Filter hinzufügen" für gezielte Filterung:

bevor Sie exportieren. Bearbeitete Zellen werden hervorgehoben.

➕ Zeilen & Spalten hinzufügen/löschen

Zeilen-Operationen (Rechtsklick auf Zeile):
• ⬆️ Zeile darüber einfügen
• ⬇️ Zeile darunter einfügen
• 🗑️ Zeile löschen (mit Bestätigungsdialog)

Spalten-Operationen (Rechtsklick auf Spaltenüberschrift):
• ⬅️ Spalte links einfügen (mit Namenseingabe)
• ➡️ Spalte rechts einfügen (mit Namenseingabe)
• 🗑️ Spalte löschen (mit Warnung über Datenverlust)
• 👁️ Spalte ausblenden

🔄 Crash-Recovery

Der Datenexplorer speichert automatisch alle 30 Sekunden Ihre Änderungen im Hintergrund.
Bei einem Absturz oder Stromausfall können Sie beim nächsten Öffnen wählen, ob die letzte Sitzung wiederhergestellt werden soll.
Recovery-Daten werden nach 24 Stunden automatisch gelöscht.

🛡️ Live-Modus Schutz:
• Automatische Backup-Kopie beim Öffnen
• Änderungs-Journal für jede Bearbeitung
• Änderungen werden erst beim Speichern in die Datei geschrieben

⚠️ Warnung bei ungespeicherten Änderungen

Beim Schließen des Datenexplorers mit ungespeicherten Änderungen erscheint eine Warnung.
Sie können wählen, ob Sie trotzdem schließen oder zurückkehren möchten.

📤 Speichern & Export

💾 Speichern / Exportieren: Speichert Änderungen in die Datei
• Überschreibt Originaldatei oder speichert als neue Datei
• Zeigt Bestätigungsdialog mit Anzahl der Änderungen
• Alle Formatierungen der Originaldatei bleiben erhalten
• Auswahl welche Arbeitsblätter mit exportiert werden sollen

📋 Arbeitsblätter wechseln

Wählen Sie ein anderes Arbeitsblatt aus dem Dropdown. Alle Ihre Änderungen werden automatisch zwischengespeichert und bleiben beim Wechsel zwischen Sheets erhalten.

🔴 Live-Modus (Windows)

Der Live-Modus ermöglicht die direkte Bearbeitung von Excel-Dateien, während Excel geöffnet bleibt.
Alle Änderungen werden sofort in Excel angezeigt – ideal zum Überprüfen und Kontrollieren.

🚀 Live-Modus starten

• Klicken Sie im Datenexplorer auf "🔴 Live öffnen" statt "📂 Datei öffnen"
• Die Datei wird in Excel geöffnet und bleibt während der Bearbeitung sichtbar
• Oben erscheint ein roter Balken mit "🔴 Live-Session aktiv"
• Hinweis: Nur unter Windows verfügbar (erfordert Microsoft Excel)

✏️ Bearbeitung im Live-Modus

Zellinhalte ändern: Klicken Sie in eine Zelle und bearbeiten Sie den Wert – die Änderung erscheint sofort in Excel

Zeilen-Operationen (Rechtsklick auf Zeile):
• ⬆️ Zeile nach oben verschieben
• ⬇️ Zeile nach unten verschieben
• 🗑️ Zeile löschen
• 🎨 Zeile farbig markieren (6 Farben verfügbar)
• ✖️ Markierung entfernen

Spalten-Operationen (Rechtsklick auf Spaltenüberschrift):
• ⬅️ Spalte nach links verschieben
• ➡️ Spalte nach rechts verschieben
• 🗑️ Spalte löschen
• 👁️ Spalte ausblenden

🔍 Filter im Live-Modus

Über die Toolbar können Sie AutoFilter in Excel setzen:
• Wählen Sie die Spalte und den Filterwert aus
• Der Filter wird in Excel aktiviert und zeigt nur passende Zeilen
• Mit "Filter zurücksetzen" werden alle Zeilen wieder angezeigt
• Filter bleiben beim Export erhalten

💾 Speichern & Schließen

💾 Exportieren: Speichert alle Änderungen dauerhaft in die Excel-Datei
❌ Live-Session beenden: Schließt Excel ohne zu speichern – alle Änderungen werden verworfen

Wichtig: Änderungen wie Zeilen-Markierungen sind nur in Excel sichtbar, werden aber erst beim Export gespeichert.

🛡️ Sicherheit

• Beim Öffnen wird automatisch eine Backup-Kopie erstellt
• Alle Änderungen werden in einem Journal protokolliert
• Excel speichert automatisch alle 2 Minuten im Hintergrund
• Bei Absturz kann der letzte Stand wiederhergestellt werden

📋 Excel-Funktionen: Was wird unterstützt?

✅ Vollständig unterstützt:
• Zellwerte, Formatierungen (Schrift, Farben, Ausrichtung)
• Formeln, Hyperlinks, Rich Text
• Verbundene Zellen (Merged Cells)
• Dropdown-Listen (Data Validation)
• Passwortgeschützte Dateien
• Ausgeblendete Zeilen und Spalten
• AutoFilter (bleibt beim Speichern erhalten)

⚠️ Bedingte Formatierung:
Bedingte Formatierung kann in der App nicht angezeigt oder bearbeitet werden.
Sie bleibt jedoch beim Laden und Speichern vollständig erhalten.

🚀 Quick Start

  1. Load source file: Click "📂 Load Source File" and select the Excel file from which rows should be copied.
  2. Load target file: Load the Excel file where the rows should be inserted.
  3. Configure columns: Define which columns should be copied.
  4. Search & Transfer: Search for rows and transfer them to the target file.

📂 Loading Files

Source file (File 1): The Excel file from which you want to copy data.
Target file (File 2): The Excel file where the data will be inserted.
After loading, you can select the desired worksheet.

🔗 Column Mapping

Click "⚙️ Configure Columns" to define:
• Start column: From which column the data will be inserted in File 2 (Column 1+2 = Flag & Comment)
• Duplicate check: Which column is used for duplicate detection
• Columns to copy: Which columns from File 1 will be transferred

🔍 Search

Enter a search term and press Enter or click "🔍 Search".
The search scans all columns of the source file. The last 15 searches are saved.

* Any number of characters (e.g., ABC*, *123*) ? Exactly one character (e.g., A?C finds ABC, ADC, ...)

Advanced search with AND/OR:

A AND B Finds rows containing both A and B A OR B Finds rows containing A or B (or both) Project AND 2025 Example: Project entries from 2025

✏️ Editing Search Results

Cells in the search results are directly editable!
Click in a cell and change the value. Edited cells are highlighted in yellow.
Changes will be applied when transferring to the target file.

📤 Transfer

Flag: A (Add), D (Delete), C (Change) or empty
Comment: Optional text for column 2
To Queue: Collects multiple rows for batch transfer
Transfer Directly: Immediately adds rows to queue and transfers

📋 Queue

The queue shows all rows marked for transfer.
👁️ Preview: Shows a diff view with all changes before transfer
✅ Transfer Directly: Writes all rows directly to the Excel target file
🗑️ Clear: Removes all rows from the queue

➕ Create New Row Manually

With "➕ New Row" you can enter rows manually without searching in the source file.
Ideal for empty rows or data not present in the source file.

📊 Data Explorer

The Data Explorer is a powerful tool for opening, browsing, editing and filtering Excel files.

📂 Open File

• Click "📊 Data Explorer" then "📂 Open File"
• Select the desired worksheet from the dropdown

🔍 Search & Filter

Full-text search: Searches all columns with wildcard support (* and ?)
Column filters: Click "+ Add Filter" for targeted filtering:

📋 Manage Columns

Show/hide columns: Via "Columns" → toggle checkboxes
Sorting: Right-click on column header opens context menu with sort options:

A→Z / Z→AAlphabetical sorting 0→9 / 9→0Numeric sorting Date ↑ / Date ↓Date sorting

Drag & Drop: Rearrange columns via drag & drop

✏️ Edit Cells

All cells are directly editable! Click in a cell and change the value.
Edited cells are highlighted in yellow.
Ctrl+Z / Ctrl+Y: Undo / redo changes

🎨 Highlight Rows

Right-click on row: Opens context menu for color highlighting
Available colors: 🟢 Green, 🟡 Yellow, 🟠 Orange, 🔴 Red, 🔵 Blue, 🟣 Purple
Highlights help with visual organization and remain when filtering.

➕ Add/Delete Rows & Columns

Row operations (right-click on row):
• ⬆️ Insert row above
• ⬇️ Insert row below
• 🗑️ Delete row (with confirmation dialog)

Column operations (right-click on column header):
• ⬅️ Insert column left (with name input)
• ➡️ Insert column right (with name input)
• 🗑️ Delete column (with data loss warning)
• 👁️ Hide column

📤 Save & Export

💾 Save / Export: Saves changes to the file
• Overwrites original file or saves as new file
• Shows confirmation dialog with number of changes
• All formatting from the original file is preserved
• Choice of which worksheets to export

🔴 Live Mode (Windows)

Live Mode enables direct editing of Excel files while Excel remains open.
All changes are immediately displayed in Excel – ideal for review and control.

🚀 Starting Live Mode

• In the Data Explorer, the Live Mode activates automatically when Excel is available
• The file opens in Excel and remains visible during editing
• A red bar appears at the top with "🔴 Live Session Active"
• Note: Only available on Windows (requires Microsoft Excel)

✏️ Editing in Live Mode

Change cell contents: Click in a cell and edit the value – the change appears immediately in Excel

Row operations (right-click on row):
• ⬆️ Move row up
• ⬇️ Move row down
• 🗑️ Delete row
• 🎨 Highlight row with color (6 colors available)
• ✖️ Clear highlight

Column operations (right-click on column header):
• ⬅️ Move column left
• ➡️ Move column right
• 🗑️ Delete column
• 👁️ Hide column

🔍 Filters in Live Mode

You can set AutoFilters in Excel via the toolbar:
• Select the column and filter value
• The filter is activated in Excel and shows only matching rows
• With "Reset Filter" all rows are shown again
• Filters are preserved on export

💾 Save & Close

💾 Export: Saves all changes permanently to the Excel file
❌ End Live Session: Closes Excel without saving – all changes are discarded

Important: Changes like row highlights are only visible in Excel, but are only saved on export.

🛡️ Safety

• A backup copy is automatically created when opening
• All changes are logged in a journal
• Changes are only written to file when you save explicitly
• In case of crash, the last state can be recovered

📄 Template Functions

Templates serve as blueprints for new monthly files. All formatting is preserved.

📂 Load Template

Loads an existing Excel file as a template for new monthly files.

📅 Create New Monthly File

Creates a copy of the template with a new name (e.g., for a new month).
The new file is automatically loaded as target file (File 2).

📁 Working Directory

Set a working directory that is used as the default location for all file dialogs.
The config.json is first searched in the working directory, then in the program folder.

💾 Configuration

Load config.json: Loads a saved configuration (column mapping, file paths)
Save config.json: Saves the current configuration for later access
💡 Ideal for teams: One config.json on the network drive for all users!

⚠️ Important Notes

• Standard mode: Target file (File 2) must be closed in Excel
• Live mode: File opens automatically in Excel and stays open
• Duplicates are automatically detected and shown as warnings
• Changes are written directly to the Excel file (no separate export needed)
• The sidebar can be collapsed with the ◀ button

📋 Excel Features: What is Supported?

✅ Fully supported:
• Cell values, formatting (font, colors, alignment)
• Formulas, hyperlinks, rich text
• Merged cells
• Dropdown lists (Data Validation)
• Password-protected files
• Hidden rows and columns
• AutoFilter (preserved on save)

⚠️ Conditional Formatting:
Conditional formatting cannot be displayed or edited in the app.
However, it is fully preserved when loading and saving.
